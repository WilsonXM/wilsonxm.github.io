为了防止出现——按某种序列Insert后出现极端情况的BST树——的情况而需要添加balance的条件，而AVL就是一种比较古老的平衡条件

### [1.3.x] Lesson 3
#### [1.3.1.x] B+ Tree——奇怪的查找树
**<font style="color:#000000;">【Definition】</font>**<font style="color:#000000;">满足下面</font>**结构性质**的树称为**阶为M的B+树**：

1. 树的根或者是叶子，或者其儿子数在 $[2,M]$ 之间；
2. 除根外，所有非树叶节点的儿子数在 $\lceil M/2 \rceil$ 和 $M$ 之间；
3. 所有的树叶都在相同的深度上；
4. **Assume each nonroot leaf also has between **$\lceil M/2 \rceil$** and M elements.**
5. **所有数据存储在叶子节点上；**
6. **所有内部节点上均含有：**
                    1. 指向该节点各儿子的指针 $P_1, P_2, P_3, \dots, P_M$ <font style="color:#585A5A;">(可能有NULL)</font>;
                    2. 分别代表在子树 $P_2, P_3, \dots, P_M$ 中的最小键值 $k_1,k_2,k_3,\dots,k_{M-1}$ ；
7. 所有树叶的**内部和树叶之间**，键值都是**从左到右严格递增**的；


【Find】

和BST类似，内部节点上的 $O(log_{\lceil M/2 \rceil}N)$ 个键值正好将其所有子节点上的偏序数据分为M块，因此B+树的查询操作的时间复杂度为 $O(log_{\lceil M/2 \rceil}N)$ ；

【Insert】

和BST类似，需要进行回溯更新内部节点键值；

冲突解决方法（若节点的children个数超过限制）：

            1. 分裂该节点，并向上递归更新；

优化方法：

            1. 探查同一父亲的其他子树中是否还有空间；
            2. 兄弟子树均饱和后再进行分裂；

#### [1.4.1.x] Leftist Heaps——为了加速堆的合并

**<font style="color:#000000;">【Definition】</font>**<font style="color:#000000;">满足下列性质的二叉树</font>称为左倾堆（树）（leftist heaps）：

_<u>堆序性质：与二叉堆相同，可分为最小堆/最大堆；</u>_

**<font style="color:#000000;">【Definition】</font>** The null path length, $Npl(X)$, of any node $X$ is the length of the shortest path from $X$ to a node without two children.  Define $Npl(NULL) = –1$.

**<font style="color:#DF2A3F;">【NOTE】</font>** $Npl(X) = Npl(C)+1$ for all children of $X$

<u>结构性质：对堆中的每个节点X，其左右儿子满足 </u> $Npl(lc) \ge Npl(rc)$；

**<font style="color:#000000;">【Theorem】</font>** A leftist tree with $r$ nodes on the right path must have at least $2^r-1$ nodes.

**【Note】** The leftist tree of $N$ nodes has a right path containing at most $\lfloor log(N+1) \rfloor$ nodes.

**【Merge】——O(logN)**

--recursive version

1. Merge( H1->Right, H2 )->递归入口
2. Attach( H2, H1->Right )
3. Swap(H1->Right, H1->Left ) if necessary
4. 递归出口->Merge时出现一棵空树

--iteration version

1. Sort the right paths without changing their left children；
2. Swap children if necessary；

注意：自底向上Swap更新，如果自顶向下Swap会改变right path上的节点使得下一步没法进行下去；

**【DeleteMin】**

1. delete the root;
2. merge the two subtrees of the original root;


#### [1.4.2.x] Skew Heaps——leftist heap的简单版本

**<font style="color:#000000;">【Definition】</font>**<font style="color:#000000;">满足下列性质的二叉树</font>称为斜堆（skew heaps）：

_<u>堆序性质：与二叉堆相同，可分为最小堆/最大堆；</u>_

_<u>结构性质：每次Merge操作都交换左右子树，除非当前节点是右路径上的最大节点；</u>_

**【Advantage】**：Skew heaps have the advantage that no extra space is required to maintain path lengths and no tests are required to determine when to swap children.

**【Note】**：It is an open problem to determine precisely the expected right path length of both leftist and skew heaps.

### [1.6.x] Lesson 6
#### [1.6.1.x] Backtracking——Theory
> 解决一个问题的可靠想法是穷举所有可能情况，逐一验证，排除错误情况，找到所有正确的答案，但是这样的方法不仅效率极低，而且对可能情况很多的问题耗时过大，因此我们需要更聪明的方法。
>

<font style="color:#000000;">【基本思想】</font>**<font style="color:#000000;">回溯</font>**<font style="color:#000000;">使我们能够</font>**<u><font style="color:#000000;">中途结束</font></u>**<u><font style="color:#000000;">对某些已知不可能情况的</font></u>**<u><font style="color:#000000;">彻底的</font></u>**<u><font style="color:#000000;">显示检查</font></u><font style="color:#000000;">（pruning：在一步内删除一大组可能性）；</font>

<font style="color:#000000;">【基本方法】</font>

1. <font style="color:#000000;">设已有部分答案</font> $(x_1,x_2,x_3,\dots,x_i)$ <font style="color:#000000;">，其中</font> $x_k \in S_K$ <font style="color:#000000;">，</font> $1 \le k \le i \le n$ <font style="color:#000000;">；</font>
2. <font style="color:#000000;">将</font> $x_{i+1}^j \in S_{i+1}$ <font style="color:#000000;">加入到答案中，检查</font> $(x_1,\dots,x_{i+1}^j)$ <font style="color:#000000;">是否可能</font><font style="color:#8A8F8D;">(satisfy the constraints)</font><font style="color:#000000;">：</font>
    1. <font style="color:#000000;">若可能，则继续加入下一个</font> $x$ <font style="color:#000000;">;</font>
    2. <font style="color:#000000;">若不可能，则从答案中删除</font> $x_{i+1}^j$ <font style="color:#000000;">，并尝试下一个</font> $x_{i+1}^{j+1} \in S_{i+1}$ <font style="color:#000000;">；如果所有的</font> $x_{i+1} \in S_{i+1}$ <font style="color:#000000;">都不满足条件，则回溯到答案</font> $(x_1,\dots,x_{i-1})$ <font style="color:#000000;">；</font>

【Template代码】

```c
/* 参数 i 表示当前答案的规模 */
bool Backtracking ( int i )
{   Found = false;
    if ( i > N )
        return true; /* solved with (x1, …, xN) */
    for ( each xi in Si ) { 
        /* check if satisfies the restriction R */
        OK = Check((x1, …, xi) , R ); /* pruning */
        if ( OK ) {
            Count xi in;
            Found = Backtracking( i+1 );
            if ( !Found )
                Undo( i ); /* recover to (x1, …, xi-1) */
        }
        if ( Found ) break; 
    }
    return Found;
}
```

```c
bool Reconstruct ( DistType X[ ], DistSet D, int N, int left, int right )
{ /* X[1]...X[left-1] and X[right+1]...X[N] are solved */
	bool Found = false;
	if ( Is_Empty( D ) )
		return true; /* solved */
	D_max = Find_Max( D );
	/*//---- option 1：X[right] = D_max ----//*/
	/* check if |D_max-X[i]| is in D for all X[i]s that have been solved */
	OK = Check( D_max, N, left, right ); /* pruning */
	if ( OK ) { /* add X[right] and update D */
		X[right] = D_max;
		for ( i=1; i<left; i++ )  Delete( |X[right]-X[i]|, D);		// 从D删去新加入的点产生的新distance
		for ( i=right+1; i<=N; i++ )  Delete( |X[right]-X[i]|, D);	// 从D删去新加入的点产生的新distance
		Found = Reconstruct ( X, D, N, left, right-1 );				// 递归下一层
		if ( !Found ) { /* if does not work, undo */
			for ( i=1; i<left; i++ )  Insert( |X[right]-X[i]|, D);		// 消除新加入点对D的影响
			for ( i=right+1; i<=N; i++ )  Insert( |X[right]-X[i]|, D);	// 消除新加入点对D的影响
		}
	}
	/* finish checking option 1 */
	if ( !Found ) { /* if option 1 does not work */
		/*//---- option 2: X[left] = X[N]-D_max ----//*/
		OK = Check( X[N]-D_max, N, left, right );
		if ( OK ) {
			X[left] = X[N] – D_max;
			for ( i=1; i<left; i++ )  Delete( |X[left]-X[i]|, D);		// 从D删去新加入的点产生的新distance
			for ( i=right+1; i<=N; i++ )  Delete( |X[left]-X[i]|, D);	// 从D删去新加入的点产生的新distance
			Found = Reconstruct (X, D, N, left+1, right );
			if ( !Found ) {
				for ( i=1; i<left; i++ ) Insert( |X[left]-X[i]|, D);		// 消除新加入点对D的影响
				for ( i=right+1; i<=N; i++ ) Insert( |X[left]-X[i]|, D);	// 消除新加入点对D的影响
			}
		}
		/* finish checking option 2 */
	} /* finish checking all the options */

	return Found;
}
```

##### 【Closest Points Problem】

    Given N points in a plane.  Find the closest pair of points.  (If two points have the same position, then that pair is the closest with distance 0.)

![alt](./assets/image55.png)

![alt](./assets/image56.png)

采用分治算法：

类似于最大子序列的分类方法；考虑<u>左边、右边、横跨左右</u>三种情况，递归的解决左右两边，并在合并时解决横跨两边；

**此时，$f(N) = cN^2$，时间复杂度为** $O(N^2)$； 

因此下面考虑对该算法进行类似剪枝的操作，不必 $\frac{N}{2} * \frac{N}{2}$ 次遍历；

**第一次剪枝：**

1. 先递归解决左右两边规模为 $\frac{N}{2}$ 的点，找出此时最小距离 $\delta$ ；
2. 遍历距离中线距离小于 $\delta$ 所有点；

![alt](./assets/image57.png)

`strip`内的点数为 $O(\sqrt{N})$ 时，可以获得 $O(logN)$ 时间开销，最坏情况是`strip`内的点是 $O(N)$
